Before you build an LLM feature, price it and time it on paper. A request flows through several **stages** (input guard, retrieval, main generation, output guard). Each stage is a dict with `name`, `in_tokens`, `out_tokens`, `price_in`, `price_out` (dollars per million tokens), `ttft` (seconds to first token) and `tps` (generated tokens per second), plus `group` (`None`, or a label shared by stages that run **in parallel**).

Implement:

- `stage_cost(s)` and `stage_latency(s)` (latency = `ttft + out_tokens/tps`; with zero output tokens it is just `ttft`).
- `pipeline(stages)` -> `{"cost", "latency"}`: costs add up; latency adds up across sequential steps, where each parallel group counts once with the **maximum** latency of its members. Steps are ordered by first appearance.
- `retry_expected_cost(cost, p_fail, max_attempts)`: expected spend when each attempt independently fails with probability `p_fail` and you retry up to `max_attempts` attempts in total (a failed attempt is still billed).
- `monthly_cost(request_cost, users, requests_per_user_per_day, days=30)`.
- `meets_budget(result, max_latency, max_cost)` -> bool (both limits inclusive).

def stage_cost(s):
    return (s["in_tokens"] * s["price_in"] + s["out_tokens"] * s["price_out"]) / 1e6

def stage_latency(s):
    return s["ttft"] + (s["out_tokens"] / s["tps"] if s["out_tokens"] else 0.0)

def pipeline(stages):
    steps = {}
    order = []
    for i, s in enumerate(stages):
        key = s["group"] if s["group"] is not None else ("__seq__", i)
        if key not in steps:
            steps[key] = []
            order.append(key)
        steps[key].append(s)
    cost = sum(stage_cost(s) for s in stages)
    latency = sum(max(stage_latency(s) for s in steps[k]) for k in order)
    return {"cost": cost, "latency": latency}

def retry_expected_cost(cost, p_fail, max_attempts):
    return cost * sum(p_fail ** k for k in range(max_attempts))

def monthly_cost(request_cost, users, requests_per_user_per_day, days=30):
    return request_cost * users * requests_per_user_per_day * days

def meets_budget(result, max_latency, max_cost):
    return result["latency"] <= max_latency and result["cost"] <= max_cost
