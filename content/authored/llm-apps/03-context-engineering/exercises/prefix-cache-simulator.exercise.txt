#@@ prompt
Providers that cache prompt prefixes bill a cache **read** at a fraction of the input price, a cache **write** at a premium, and everything else at the plain price. A cache entry is a **prefix** of the prompt: change one early token and every later token misses. You will simulate this offline.

A request is `(t, segments)` with `t` in seconds and `segments` a list of `(key, tokens, cacheable)`. A prefix is cacheable if it ends at a segment with `cacheable=True` and holds at least `min_tokens` tokens. Implement `simulate(requests, price=3.0, write_mult=1.25, read_mult=0.1, ttl=300, min_tokens=1024)` (`price` in dollars per million input tokens), processing requests in order:

1. Among the cacheable prefixes of the request, find the **longest** one whose key tuple is in the cache and was last used at most `ttl` seconds ago. Its tokens are **read**.
2. Tokens after it, up to the end of the request's last cacheable prefix, are **written** (billed at `write_mult`). Everything after that is billed plain.
3. Bill `(read*read_mult + write*write_mult + plain) * price / 1e6`.
4. Insert or refresh the entry (time `t`) of **every** cacheable prefix of this request.

Return `{"total_tokens", "read_tokens", "hit_rate", "cost", "baseline", "savings"}` where `hit_rate = read_tokens/total_tokens`, `baseline` is the cost with no caching, and `savings = 1 - cost/baseline`.

Also implement `avg_cost_ratio(n_reads, write_mult, read_mult)` (average cost per use relative to no caching, for 1 write followed by `n_reads` reads) and `breakeven_reads(write_mult, read_mult)` (smallest `n>=1` for which that ratio is below 1).

def conv(n, dt=10):
    """A chat: system + tools (cacheable), n-1 past turns of 500 tokens (cacheable), a fresh 200-token user message."""
    reqs = []
    for i in range(n):
        segs = [("sys", 2000, True), ("tools", 1500, True)] + [(f"h{j}", 500, True) for j in range(i)] + [(f"u{i}", 200, False)]
        reqs.append((i * dt, segs))
    return reqs

def simulate(requests, price=3.0, write_mult=1.25, read_mult=0.1, ttl=300, min_tokens=1024):
    cache = {}
    tot = read_t = 0
    cost = 0.0
    for t, segs in requests:
        keys = [s[0] for s in segs]
        cum = [0]
        for s in segs:
            cum.append(cum[-1] + s[1])
        total = cum[-1]
        ends = [k + 1 for k, s in enumerate(segs) if s[2] and cum[k + 1] >= min_tokens]
        hit = 0
        for k in sorted(ends, reverse=True):
            e = cache.get(tuple(keys[:k]))
            if e is not None and t - e <= ttl:
                hit = k
                break
        read = cum[hit]
        last = max(ends) if ends else 0
        write = cum[last] - cum[hit]
        plain = total - read - write
        cost += (read * read_mult + write * write_mult + plain) * price / 1e6
        read_t += read
        tot += total
        for k in ends:
            cache[tuple(keys[:k])] = t
    base = tot * price / 1e6
    return {"total_tokens": tot, "read_tokens": read_t, "hit_rate": read_t / tot, "cost": cost, "baseline": base, "savings": 1 - cost / base}

def avg_cost_ratio(n_reads, write_mult=1.25, read_mult=0.1):
    return (write_mult + read_mult * n_reads) / (n_reads + 1)

def breakeven_reads(write_mult=1.25, read_mult=0.1):
    n = 1
    while avg_cost_ratio(n, write_mult, read_mult) >= 1:
        n += 1
    return n
