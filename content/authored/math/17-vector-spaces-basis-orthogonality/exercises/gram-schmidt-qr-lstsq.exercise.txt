Implement, without calling `np.linalg.qr` or `np.linalg.lstsq` in your own code:

- `gram_schmidt(A)` - modified Gram-Schmidt for an `(n, m)` matrix with independent columns. Return `Q` `(n, m)` with orthonormal columns and upper-triangular `R` `(m, m)` with a positive diagonal, so `A = Q @ R`.
- `back_substitute(R, b)` - solve `R x = b` for upper-triangular `R`.
- `lstsq_qr(A, b)` - least squares through `R x = Q^T b`. Caveat: with Gram-Schmidt the loss of orthogonality makes `Q.T @ b` noticeably inaccurate here (error about `1e-7`). The standard remedy is to run Gram-Schmidt on the augmented matrix `[A | b]`; the last column of the resulting `R` is then `Q^T b` computed stably (this is the textbook modified-Gram-Schmidt least-squares trick). `np.linalg.qr` avoids the issue with Householder reflections.
- `lstsq_normal(A, b)` - least squares through the normal equations `A^T A x = A^T b` (use `np.linalg.solve`, not an explicit inverse).

import numpy as np

def gram_schmidt(A):
    A = np.asarray(A, dtype=float)
    n, m = A.shape
    Q = np.zeros((n, m))
    R = np.zeros((m, m))
    V = A.copy()
    for k in range(m):
        R[k, k] = np.linalg.norm(V[:, k])
        Q[:, k] = V[:, k] / R[k, k]
        for j in range(k + 1, m):
            R[k, j] = Q[:, k] @ V[:, j]
            V[:, j] -= R[k, j] * Q[:, k]
    return Q, R

def back_substitute(R, b):
    m = R.shape[0]
    x = np.zeros(m)
    for i in range(m - 1, -1, -1):
        x[i] = (b[i] - R[i, i + 1:] @ x[i + 1:]) / R[i, i]
    return x

def lstsq_qr(A, b):
    m = A.shape[1]
    _, R = gram_schmidt(np.column_stack([A, b]))
    return back_substitute(R[:m, :m], R[:m, m])

def lstsq_normal(A, b):
    return np.linalg.solve(A.T @ A, A.T @ b)
