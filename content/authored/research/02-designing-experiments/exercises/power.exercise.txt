Planning an experiment means asking how many runs you need before you spend the compute. The helpers `norm_ppf`, `t_crit` and `welch_t` are given.

1. `n_per_group(delta, sigma, alpha=0.05, power=0.8)` -> smallest integer `n` per group for a two-sided two-sample comparison of means, from the normal-approximation formula `n = 2 (z_{1-alpha/2} + z_{power})^2 sigma^2 / delta^2` (round **up**).
2. `simulated_power(delta, sigma, n, n_sims=2000, seed=0)` -> fraction of simulated experiments in which Welch's test rejects at the 5 percent level. Each simulation draws group A from `N(0, sigma^2)` and group B from `N(delta, sigma^2)`, `n` values each; reject when `abs(t) > t_crit(int(round(df)))`. Use `np.random.default_rng(seed)` once, outside the loop.
3. `bonferroni(p, alpha=0.05)` -> boolean array: reject `p_i <= alpha / m`.
4. `benjamini_hochberg(p, q=0.05)` -> boolean array in the **original order**: the step-up procedure that controls the false discovery rate at `q`.

import math
import numpy as np

T975 = [12.706, 4.303, 3.182, 2.776, 2.571, 2.447, 2.365, 2.306, 2.262, 2.228,
        2.201, 2.179, 2.160, 2.145, 2.131, 2.120, 2.110, 2.101, 2.093, 2.086,
        2.080, 2.074, 2.069, 2.064, 2.060, 2.056, 2.052, 2.048, 2.045, 2.042]

def t_crit(df):
    if df <= 30:
        return T975[max(df, 1) - 1]
    z = 1.959963984540054
    return z + (z**3 + z) / (4 * df) + (5 * z**5 + 16 * z**3 + 3 * z) / (96 * df**2)

def norm_ppf(p):
    lo, hi = -10.0, 10.0
    for _ in range(200):
        mid = (lo + hi) / 2
        if 0.5 * (1 + math.erf(mid / math.sqrt(2))) < p:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2

def welch_t(a, b):
    na, nb = len(a), len(b)
    va, vb = a.var(ddof=1) / na, b.var(ddof=1) / nb
    t = (a.mean() - b.mean()) / math.sqrt(va + vb)
    df = (va + vb) ** 2 / (va ** 2 / (na - 1) + vb ** 2 / (nb - 1))
    return t, df

def n_per_group(delta, sigma, alpha=0.05, power=0.8):
    za = norm_ppf(1 - alpha / 2)
    zb = norm_ppf(power)
    return int(math.ceil(2 * (za + zb) ** 2 * sigma ** 2 / delta ** 2))

def simulated_power(delta, sigma, n, n_sims=2000, seed=0):
    rng = np.random.default_rng(seed)
    rejections = 0
    for _ in range(n_sims):
        a = rng.normal(0.0, sigma, n)
        b = rng.normal(delta, sigma, n)
        t, df = welch_t(a, b)
        if abs(t) > t_crit(int(round(df))):
            rejections += 1
    return rejections / n_sims

def bonferroni(p, alpha=0.05):
    p = np.asarray(p, dtype=float)
    return p <= alpha / len(p)

def benjamini_hochberg(p, q=0.05):
    p = np.asarray(p, dtype=float)
    m = len(p)
    order = np.argsort(p)
    passing = np.nonzero(p[order] <= q * np.arange(1, m + 1) / m)[0]
    reject = np.zeros(m, dtype=bool)
    if len(passing):
        reject[order[: passing.max() + 1]] = True
    return reject
