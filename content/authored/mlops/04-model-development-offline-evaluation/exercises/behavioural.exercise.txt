Behavioural tests catch problems that a held-out accuracy number cannot. `predict` below is any function that maps a matrix `X` of shape `(n, d)` to predictions of shape `(n,)`.

- `perturbation_drop(predict, X, y, noise_std, rng)` -> accuracy on clean `X` minus accuracy on `X + Gaussian noise` (noise drawn with `rng.normal(0, noise_std, X.shape)`).
- `invariance_flip_rate(predict, X, col, new_value)` -> share of rows whose prediction changes when column `col` is overwritten with `new_value` (a sensitive attribute should not matter).
- `directional_violation_rate(score, X, col, delta, direction)` -> share of rows for which adding `delta` to column `col` moves the score the wrong way (`direction=+1` means the score should not decrease; `-1` means it should not increase).

import numpy as np

def perturbation_drop(predict, X, y, noise_std, rng):
    clean = np.mean(predict(X) == y)
    noisy = np.mean(predict(X + rng.normal(0, noise_std, X.shape)) == y)
    return float(clean - noisy)

def invariance_flip_rate(predict, X, col, new_value):
    X2 = X.copy()
    X2[:, col] = new_value
    return float(np.mean(predict(X) != predict(X2)))

def directional_violation_rate(score, X, col, delta, direction):
    X2 = X.copy()
    X2[:, col] = X2[:, col] + delta
    diff = score(X2) - score(X)
    bad = diff < 0 if direction > 0 else diff > 0
    return float(np.mean(bad))
