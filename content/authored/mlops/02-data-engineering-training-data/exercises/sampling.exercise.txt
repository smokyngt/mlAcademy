Two samplers you need when data does not fit in memory or when a class is rare.

- `reservoir_sample(stream, k, rng)`: given any iterable `stream` of unknown length and a NumPy generator `rng`, return a list of `k` items such that **every** item of the stream has the same probability `k/n` of being kept (`n` = stream length so far). Use one pass and O(k) memory. If the stream has fewer than `k` items, return all of them.
- `stratified_sample(labels, frac, rng)`: return the **sorted** array of indices of a sample that contains `round(frac * count)` items (at least 1) from each class, drawn without replacement.

import numpy as np

def reservoir_sample(stream, k, rng):
    res = []
    for n, x in enumerate(stream):
        if n < k:
            res.append(x)
        else:
            j = int(rng.integers(0, n + 1))
            if j < k:
                res[j] = x
    return res

def stratified_sample(labels, frac, rng):
    labels = np.asarray(labels)
    out = []
    for c in np.unique(labels):
        idx = np.flatnonzero(labels == c)
        m = max(1, int(round(frac * len(idx))))
        out.extend(rng.choice(idx, size=m, replace=False).tolist())
    return np.array(sorted(out))
