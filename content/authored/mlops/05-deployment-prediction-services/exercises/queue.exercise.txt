Simulate a model server. Times are in seconds. `arrivals` is a sorted NumPy array of request arrival times.

- `fifo_latencies(arrivals, service)` -> array of latencies (waiting + service) for a single server that handles one request at a time; `service` is an array of service times, one per request.
- `batched_latencies(arrivals, max_batch, max_wait, a, b)` -> `(latencies, batch_sizes)` for a server that processes requests in batches. A batch takes `a + b * size` seconds. The server forms a batch from the oldest waiting request and the following requests: it starts when the batch is full (`max_batch` requests have arrived) or when the oldest request has waited `max_wait`, whichever is earlier, but never before the server is free. All requests among the next `max_batch` that have arrived by the start time join the batch.
- `mm1_mean_latency(lam, mu)` -> theoretical mean latency `1 / (mu - lam)` of an M/M/1 queue (Poisson arrivals at rate `lam`, exponential service at rate `mu`, `lam < mu`).

import numpy as np

def fifo_latencies(arrivals, service):
    lat = np.empty(len(arrivals))
    free = 0.0
    for i in range(len(arrivals)):
        start = max(arrivals[i], free)
        free = start + service[i]
        lat[i] = free - arrivals[i]
    return lat

def batched_latencies(arrivals, max_batch, max_wait, a, b):
    n = len(arrivals)
    lat = np.empty(n)
    sizes = []
    free = 0.0
    i = 0
    while i < n:
        last = min(i + max_batch - 1, n - 1)
        start = max(free, min(arrivals[i] + max_wait, arrivals[last]))
        k = i
        while k < n and k < i + max_batch and arrivals[k] <= start:
            k += 1
        finish = start + a + b * (k - i)
        lat[i:k] = finish - arrivals[i:k]
        sizes.append(k - i)
        free = finish
        i = k
    return lat, np.array(sizes)

def mm1_mean_latency(lam, mu):
    return 1.0 / (mu - lam)
