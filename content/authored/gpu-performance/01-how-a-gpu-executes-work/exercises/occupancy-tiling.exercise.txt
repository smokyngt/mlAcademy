**Part A: occupancy.** An SM (streaming multiprocessor) keeps a limited number of threads resident, and each block of threads needs registers and shared memory. Implement

`occupancy(threads_per_block, regs_per_thread, smem_per_block, sm)` where `sm` is a dict with keys `max_threads`, `max_blocks`, `max_warps`, `regs`, `smem` (per-SM limits). Warp size is 32.

- `warps_per_block = ceil(threads_per_block / 32)`
- registers are allocated per warp: `regs_per_block = regs_per_thread * 32 * warps_per_block`
- `blocks = min(max_blocks, max_threads // threads_per_block, regs // regs_per_block, smem // smem_per_block)` (skip the shared-memory term if `smem_per_block == 0`)
- return `(blocks, occupancy)` where `occupancy = blocks * warps_per_block / max_warps` capped at 1.0 (0 blocks gives `(0, 0.0)`).

**Part B: tiled matmul traffic.** For `C = A @ B` with `A` of shape `(M, K)` and `B` of shape `(K, N)`, count the bytes moved between global memory and the SMs.

`matmul_global_bytes(M, N, K, tile=None, elem_bytes=4)`: with `tile=None` (naive, every thread reads its own row and column) the loads are `2*M*N*K` elements. With `tile=T` (a `T x T` thread block stages `T x T` tiles of A and B in shared memory; `M, N, K` multiples of `T`) each element of A is loaded `N/T` times and each element of B `M/T` times. Add the `M*N` stores of C. Return **bytes**.

`matmul_intensity(M, N, K, tile=None, elem_bytes=4)`: FLOPs (`2*M*N*K`) divided by that byte count.

import numpy as np

def occupancy(threads_per_block, regs_per_thread, smem_per_block, sm):
    wpb = -(-threads_per_block // 32)
    regs_per_block = regs_per_thread * 32 * wpb
    limits = [sm["max_blocks"], sm["max_threads"] // threads_per_block, sm["regs"] // regs_per_block]
    if smem_per_block > 0:
        limits.append(sm["smem"] // smem_per_block)
    blocks = min(limits)
    if blocks <= 0:
        return (0, 0.0)
    return (blocks, min(1.0, blocks * wpb / sm["max_warps"]))

def matmul_global_bytes(M, N, K, tile=None, elem_bytes=4):
    if tile is None:
        loads = 2 * M * N * K
    else:
        loads = M * K * (N // tile) + K * N * (M // tile)
    return elem_bytes * (loads + M * N)

def matmul_intensity(M, N, K, tile=None, elem_bytes=4):
    return 2 * M * N * K / matmul_global_bytes(M, N, K, tile, elem_bytes)
