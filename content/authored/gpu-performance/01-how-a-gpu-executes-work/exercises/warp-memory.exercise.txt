#@@ prompt
A GPU runs threads in groups of 32 called **warps**. Implement four small counters that model the classic ways a warp wastes work.

1. `divergence_passes(cond, warp=32)`: `cond` is a boolean array with one entry per thread (the condition of an `if ... else ...`). A warp executes the `if` side in one pass if any of its threads takes it, and the `else` side in one pass if any thread takes that. Return the **total number of passes** over all warps (a warp with a uniform condition costs 1 pass, a split warp costs 2).
2. `branch_efficiency(cond, warp=32)`: `n_warps / divergence_passes(cond)` (1.0 means no divergence, 0.5 means every warp paid double).
3. `coalesced_transactions(index, elem_bytes=4, line=128, warp=32)`: `index` is an integer array with the element each thread loads from global memory. For every warp, count the distinct `line`-byte segments touched; return the **total** over all warps.
4. `bank_conflict_degree(word_index, banks=32)`: `word_index` holds the 4-byte word each of the 32 threads of ONE warp reads from shared memory. Return the largest number of **distinct words** that fall into the same bank (`word % banks`). Several threads reading the identical word is a broadcast and counts once. 1 means conflict-free.

import numpy as np

def divergence_passes(cond, warp=32):
    c = np.asarray(cond, dtype=bool).reshape(-1, warp)
    return int(c.any(axis=1).sum() + (~c).any(axis=1).sum())

def branch_efficiency(cond, warp=32):
    n_warps = np.asarray(cond).size // warp
    return n_warps / divergence_passes(cond, warp)

def coalesced_transactions(index, elem_bytes=4, line=128, warp=32):
    idx = np.asarray(index, dtype=np.int64).reshape(-1, warp)
    total = 0
    for row in idx:
        total += len(set((row * elem_bytes // line).tolist()))
    return total

def bank_conflict_degree(word_index, banks=32):
    words = set(int(x) for x in np.asarray(word_index).ravel())
    counts = {}
    for x in words:
        counts[x % banks] = counts.get(x % banks, 0) + 1
    return max(counts.values())
