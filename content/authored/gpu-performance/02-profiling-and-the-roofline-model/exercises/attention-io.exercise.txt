Model ONE attention head with sequence length `N`, head dimension `d`, `elem_bytes` per number (2 for fp16). Our convention: the two matmuls cost `2*N*N*d` FLOPs each, the softmax `5*N*N`.

- `attn_flops(N, d)`: total FLOPs.
- `attn_bytes_standard(N, d, elem_bytes)`: global-memory traffic when each step is a separate kernel: read Q and K, write S; read S, write P; read P and V, write O. Count it as `elem_bytes * (4*N*d + 4*N*N)`.
- `attn_bytes_tiled(N, d, Br, elem_bytes)`: traffic of a FlashAttention-style kernel with query blocks of `Br` rows (`N` a multiple of `Br`): Q read once, every one of the `N/Br` query blocks streams all of K and V, O written once.
- `tile_fits(Br, Bc, d, elem_bytes, sram_bytes)`: does one iteration fit in fast memory? Count the Q tile (`Br*d`), the K and V tiles (`2*Bc*d`), the score tile (`Br*Bc`) and the output accumulator (`Br*d`).
- `intensity(flops, nbytes)` and `bound(intensity, ridge)` returning `"memory"` or `"compute"`.
- `largest_br(N, d, elem_bytes, sram_bytes)`: the largest `Br` that is a power of two, divides `N`, and satisfies `tile_fits(Br, Br, ...)`.

#@@ solution
import numpy as np

def attn_flops(N, d):
    return 4 * N * N * d + 5 * N * N

def attn_bytes_standard(N, d, elem_bytes):
    return elem_bytes * (4 * N * d + 4 * N * N)

def attn_bytes_tiled(N, d, Br, elem_bytes):
    return elem_bytes * (N * d + 2 * N * d * (N // Br) + N * d)

def tile_fits(Br, Bc, d, elem_bytes, sram_bytes):
    elems = Br * d + 2 * Bc * d + Br * Bc + Br * d
    return elems * elem_bytes <= sram_bytes

def intensity(flops, nbytes):
    return flops / nbytes

def bound(inten, ridge):
    return "memory" if inten < ridge else "compute"

def largest_br(N, d, elem_bytes, sram_bytes):
    best = 0
    br = 1
    while br <= N:
        if N % br == 0 and tile_fits(br, br, d, elem_bytes, sram_bytes):
            best = br
        br *= 2
    return best
