Three small models of how a training run uses memory and time.

1. `training_bytes(n_params, mode)` -> bytes for weights + gradients + optimiser state (no activations), where `mode` is `"fp32"` (fp32 weights, fp32 grads, Adam m and v in fp32) or `"mixed"` (bf16 weights, bf16 grads, plus an fp32 master copy and fp32 Adam m and v).
2. `activation_bytes(n_layers, batch, seq, d_model, elem_bytes)`: the rough rule `12 * batch * seq * d_model * elem_bytes` per layer, times `n_layers`.
3. `checkpoint_model(n_layers, k, a_layer, a_in)` -> `(memory, compute_factor)` for checkpointing every `k` layers (`k` divides `n_layers`): `memory = (n_layers/k) * a_in + k * a_layer`. Recomputing one extra forward pass over every layer makes a step cost `1 + 1 + 2 = 4` units instead of `1 + 2 = 3`, so `compute_factor = 4/3`. The value `k = 0` means "no checkpointing": return `(n_layers * a_layer, 1.0)`.
4. `best_k(n_layers, a_layer, a_in)`: the divisor `k` of `n_layers` minimising `checkpoint_model` memory (smallest `k` on ties).
5. `accumulated_gradient(X, y, w, n_micro)`: gradient of the mean-squared-error `mean((X @ w - y)**2)` with respect to `w`, computed by splitting the batch into `n_micro` equal micro-batches, accumulating `grad / n_micro`.
6. `loader_step_time(load, compute, workers, prefetch)`: seconds per step. Without prefetch the step waits for loading: `load / workers + compute`. With prefetch loading overlaps compute: `max(load / workers, compute)`.

import numpy as np

def training_bytes(n_params, mode):
    if mode == "fp32":
        per = 4 + 4 + 4 + 4
    elif mode == "mixed":
        per = 2 + 2 + 4 + 4 + 4
    else:
        raise ValueError(mode)
    return n_params * per

def activation_bytes(n_layers, batch, seq, d_model, elem_bytes):
    return n_layers * 12 * batch * seq * d_model * elem_bytes

def checkpoint_model(n_layers, k, a_layer, a_in):
    if k == 0:
        return (n_layers * a_layer, 1.0)
    return ((n_layers // k) * a_in + k * a_layer, 4.0 / 3.0)

def best_k(n_layers, a_layer, a_in):
    best, best_mem = None, None
    for k in range(1, n_layers + 1):
        if n_layers % k == 0:
            mem = checkpoint_model(n_layers, k, a_layer, a_in)[0]
            if best_mem is None or mem < best_mem - 1e-12:
                best, best_mem = k, mem
    return best

def accumulated_gradient(X, y, w, n_micro):
    g = np.zeros_like(w, dtype=float)
    for Xb, yb in zip(np.array_split(X, n_micro), np.array_split(y, n_micro)):
        g += 2 * Xb.T @ (Xb @ w - yb) / len(Xb) / n_micro
    return g

def loader_step_time(load, compute, workers, prefetch):
    if prefetch:
        return max(load / workers, compute)
    return load / workers + compute
