Float16 has a small range, so tiny gradients silently become 0. Simulate the problem and its standard cure with NumPy's real `float16`.

1. `format_stats(e, m)` -> dict with `max`, `min_normal`, `min_subnormal`, `eps` for an IEEE-style format with `e` exponent bits and `m` mantissa bits.
2. `underflow_fraction(grads, scale)`: `grads` is a float32 array. Compute `(grads * scale).astype(np.float16)` and return the fraction of the **originally non-zero** entries that became exactly 0.
3. `has_overflow(grads, scale)`: `True` if any entry of `(grads * scale).astype(np.float16)` is not finite.
4. `scaled_gradient(grads, scale)`: scale in float32, cast to float16 (this is what backward produces), then cast back to float32 and **divide by the scale**; return that float32 array.
5. `update_scale(scale, found_inf, good_steps, growth_interval=4)` -> `(new_scale, new_good_steps)` implementing dynamic loss scaling (halve on overflow, double after `growth_interval` consecutive good steps).
6. `accumulate(w0, delta, n, dtype)`: start from `w0` stored in `dtype`, add `delta` `n` times, **rounding to `dtype` after every addition**; return the final value as a Python float. This shows why optimisers keep float32 master weights.

import numpy as np

def format_stats(e, m):
    bias = 2 ** (e - 1) - 1
    return {"max": (2.0 - 2.0 ** -m) * 2.0 ** bias,
            "min_normal": 2.0 ** (1 - bias),
            "min_subnormal": 2.0 ** (1 - bias - m),
            "eps": 2.0 ** -m}

def underflow_fraction(grads, scale):
    g = np.asarray(grads, dtype=np.float32)
    nz = g != 0
    with np.errstate(over="ignore"):
        h = (g * np.float32(scale)).astype(np.float16)
    return float(np.sum(nz & (h == 0)) / np.sum(nz))

def has_overflow(grads, scale):
    g = np.asarray(grads, dtype=np.float32)
    with np.errstate(over="ignore"):
        h = (g * np.float32(scale)).astype(np.float16)
    return bool(not np.all(np.isfinite(h)))

def scaled_gradient(grads, scale):
    g = np.asarray(grads, dtype=np.float32)
    with np.errstate(over="ignore"):
        h = (g * np.float32(scale)).astype(np.float16)
    return h.astype(np.float32) / np.float32(scale)

def update_scale(scale, found_inf, good_steps, growth_interval=4):
    if found_inf:
        return scale / 2.0, 0
    good_steps += 1
    if good_steps >= growth_interval:
        return scale * 2.0, 0
    return scale, good_steps

def accumulate(w0, delta, n, dtype):
    w = dtype(w0)
    d = dtype(delta)
    for _ in range(n):
        w = dtype(w + d)
    return float(w)
