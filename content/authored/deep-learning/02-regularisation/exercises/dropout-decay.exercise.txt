Implement three small pieces.

1. `Dropout(p, seed)` with `forward(x, train=True)` and `backward(dy)`. Use **inverted** scaling: kept units are multiplied by `1/(1-p)`. In evaluation mode (`train=False`) return `x` unchanged. `backward` must reuse the mask from the last training forward pass (dropped units get zero gradient, kept units get `dy/(1-p)`); if the last forward was in evaluation mode, backward returns `dy`.
2. `decay_step(W, g, lr, lam)` returning the new weights after one gradient step on `loss + lam/2 * ||W||^2`, written as shrink-then-step: `(1 - lr*lam) * W - lr * g`. Do not modify `W` in place.
3. `ridge_map(X, y, sigma2, tau2)` returning the MAP weights of a linear model with Gaussian noise (variance `sigma2`) and a zero-mean Gaussian prior (variance `tau2`) on the weights, i.e. ridge regression with `lam = sigma2 / tau2`.

import numpy as np

class Dropout:
    def __init__(self, p, seed=0):
        self.p = p
        self.rng = np.random.default_rng(seed)
        self.mask = None
    def forward(self, x, train=True):
        if not train or self.p == 0:
            self.mask = None
            return x
        self.mask = (self.rng.random(x.shape) >= self.p) / (1 - self.p)
        return x * self.mask
    def backward(self, dy):
        return dy if self.mask is None else dy * self.mask

def decay_step(W, g, lr, lam):
    return (1 - lr * lam) * W - lr * g

def ridge_map(X, y, sigma2, tau2):
    lam = sigma2 / tau2
    return np.linalg.solve(X.T @ X + lam * np.eye(X.shape[1]), X.T @ y)

d = Dropout(0.5, seed=1)
x = np.full((4, 3), 2.0)
print(d.forward(x))
