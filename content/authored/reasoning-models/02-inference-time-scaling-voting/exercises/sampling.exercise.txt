Decoding turns next-token scores (logits) into a token. Implement the pieces with NumPy:

- `softmax_T(logits, T=1.0)`: probabilities from logits divided by temperature `T` (numerically stable). `T` must be positive; raise `ValueError` otherwise.
- `top_p_filter(probs, top_p)`: keep the smallest set of most-likely tokens whose cumulative mass reaches `top_p` (in practice: keep a token while the mass *before* it is `< top_p`; always keep the most likely token), zero out the others (in the original positions) and renormalise. `top_p=None` or `>= 1` returns a copy unchanged.
- `sample_index(probs, u)`: the inverse-CDF draw: the smallest index `i` with `cumsum(probs)[i] > u`, for a uniform `u` in `[0, 1)`.
- `sampling_frequencies(probs, num=1000)`: draw with the deterministic grid `u_j = (j + 0.5) / num` for `j = 0..num-1` and return the fraction of draws per index (an array summing to 1). This shows what a sampler does without any randomness.

import numpy as np


def softmax_T(logits, T=1.0):
    if T <= 0:
        raise ValueError("temperature must be positive")
    z = np.asarray(logits, float) / T
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()


def top_p_filter(probs, top_p):
    probs = np.asarray(probs, float)
    if top_p is None or top_p >= 1.0:
        return probs.copy()
    order = np.argsort(-probs, kind="stable")
    sorted_p = probs[order]
    prefix = np.cumsum(sorted_p) - sorted_p
    keep = prefix < top_p
    keep[0] = True
    out = np.zeros_like(probs)
    out[order[keep]] = sorted_p[keep]
    return out / out.sum()


def sample_index(probs, u):
    return int(np.searchsorted(np.cumsum(probs), u, side="right"))


def sampling_frequencies(probs, num=1000):
    probs = np.asarray(probs, float)
    counts = np.zeros(len(probs))
    for j in range(num):
        counts[sample_index(probs, (j + 0.5) / num)] += 1
    return counts / num
