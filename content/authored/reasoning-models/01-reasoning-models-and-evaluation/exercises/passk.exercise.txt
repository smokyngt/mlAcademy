You sample `n` solutions to a problem and `c` of them are verified correct. **pass@k** is the probability that at least one of `k` solutions, drawn from the model, is correct.

Implement:

- `pass_at_k(n, c, k)`: the **unbiased** estimator `1 - C(n-c, k) / C(n, k)` (evaluate it with the stable product form from the hints; return `1.0` when `n - c < k`).
- `naive_pass_at_k(n, c, k)`: the plug-in estimator `1 - (1 - c/n)**k`, which treats the measured rate as if it were the true one.
- `expected_estimate(estimator, n, p, k)`: the exact expectation of an estimator when the true per-sample success probability is `p`, i.e. `sum_c Binomial(c; n, p) * estimator(n, c, k)`.
- `accuracy_se(c, n)`: the standard error `sqrt(p(1-p)/n)` of an accuracy `p = c/n`.
- `wilson_interval(c, n, z=1.96)`: the Wilson score interval `(low, high)` for an accuracy.
- `mean_pass_at_k(counts, n, k)`: the benchmark score, i.e. the mean of `pass_at_k(n, c, k)` over a list of per-problem correct counts.

import numpy as np
from math import comb, sqrt


def pass_at_k(n, c, k):
    if n - c < k:
        return 1.0
    prod = 1.0
    for i in range(n - c + 1, n + 1):
        prod *= 1.0 - k / i
    return 1.0 - prod


def naive_pass_at_k(n, c, k):
    return 1.0 - (1.0 - c / n) ** k


def expected_estimate(estimator, n, p, k):
    return sum(comb(n, c) * p ** c * (1 - p) ** (n - c) * estimator(n, c, k) for c in range(n + 1))


def accuracy_se(c, n):
    p = c / n
    return sqrt(p * (1 - p) / n)


def wilson_interval(c, n, z=1.96):
    p = c / n
    d = 1 + z * z / n
    centre = (p + z * z / (2 * n)) / d
    half = z * sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, centre - half), min(1.0, centre + half)


def mean_pass_at_k(counts, n, k):
    return float(np.mean([pass_at_k(n, c, k) for c in counts]))
