Chapter 7 of the book lists many modifications of GRPO. Implement the core mechanics and see their effect numerically.

- `group_advantages(rewards, eps=1e-4, std_norm=True)`: as in the previous lesson (`ddof=1`; `std_norm=False` only centres).
- `abs_advantage_mass(k, G, std_norm)`: the total absolute advantage `sum_i |A_i|` of a group with `k` correct rollouts out of `G` (use `eps = 0`), a measure of how much "push" the problem gets.
- `token_weights(adv, lengths, mode)`: the weight of every **token** of each rollout in the loss `-sum_tokens weight * logp_token`, for `mode` in `"seq_sum"` (`A_i/G`, the book's loss), `"seq_mean"` (`A_i/(G L_i)`, each sequence's log-prob averaged over its tokens) and `"token_mean"` (`A_i / sum_j L_j`, one average over all tokens in the group).
- `sequence_push(adv, lengths, mode)`: the total weight on each rollout (`token weight * L_i`).
- `filter_groups(groups)`: keep only the groups (lists of rewards) with a non-zero spread (dynamic filtering of zero-signal prompts).
- `clip_objective(ratio, adv, eps_low, eps_high)`: elementwise `min(ratio * adv, clip(ratio, 1-eps_low, 1+eps_high) * adv)`; a larger `eps_high` ("clip higher") lets likelier tokens keep growing.
- `sequence_ratio(logp_new, logp_old, length, mode)`: the sequence-level importance ratio, `exp(logp_new - logp_old)` for `"seq"` and its length-normalised version `exp((logp_new - logp_old) / length)` for `"length_norm"`.
- `kl_term(logratios, mode, beta)`: `beta` times the **sum** (`"sum"`) or **mean** (`"mean"`) of the per-token log-ratios `log pi - log pi_ref` of one rollout.
- `mean_entropy(logits)`: mean over rows of the entropy of `softmax(row)`; `logits` has shape `(steps, vocab)`.

import numpy as np


def group_advantages(rewards, eps=1e-4, std_norm=True):
    r = np.asarray(rewards, float)
    d = r - r.mean()
    if not std_norm:
        return d
    return d / (r.std(ddof=1) + eps)


def abs_advantage_mass(k, G, std_norm):
    r = np.array([1.0] * k + [0.0] * (G - k))
    return float(np.abs(group_advantages(r, eps=0.0, std_norm=std_norm)).sum())


def token_weights(adv, lengths, mode):
    adv = np.asarray(adv, float)
    L = np.asarray(lengths, float)
    G = len(adv)
    if mode == "seq_sum":
        return adv / G
    if mode == "seq_mean":
        return adv / (G * L)
    if mode == "token_mean":
        return adv / L.sum()
    raise ValueError(mode)


def sequence_push(adv, lengths, mode):
    return token_weights(adv, lengths, mode) * np.asarray(lengths, float)


def filter_groups(groups):
    return [g for g in groups if max(g) != min(g)]


def clip_objective(ratio, adv, eps_low, eps_high):
    ratio = np.asarray(ratio, float)
    adv = np.asarray(adv, float)
    return np.minimum(ratio * adv, np.clip(ratio, 1 - eps_low, 1 + eps_high) * adv)


def sequence_ratio(logp_new, logp_old, length, mode):
    d = logp_new - logp_old
    if mode == "length_norm":
        d = d / length
    return float(np.exp(d))


def kl_term(logratios, mode, beta):
    lr = np.asarray(logratios, float)
    return float(beta * (lr.sum() if mode == "sum" else lr.mean()))


def mean_entropy(logits):
    z = np.asarray(logits, float)
    z = z - z.max(axis=-1, keepdims=True)
    lp = z - np.log(np.exp(z).sum(axis=-1, keepdims=True))
    p = np.exp(lp)
    return float(np.mean(-(p * lp).sum(axis=-1)))
