Self-refinement alternates **critique** and **revise** steps. A loop needs rules for what to accept and when to stop, otherwise it spends compute (two model calls per round) for nothing or makes a good answer worse. Implement the controller with plain Python; the model is replaced by functions you are given.

`refine_loop(initial, critique_fn, revise_fn, score_fn, max_iters=3, patience=2, target=None, ok_marker="LGTM", accept="not_worse")` returns a dict with

- `final`: the draft that is kept,
- `score`: its score,
- `stop_reason`: one of `"target"`, `"critique_ok"`, `"patience"`, `"max_iters"`,
- `llm_calls`: number of critique plus revise calls made,
- `history`: a list with one dict per iteration containing `iteration`, `critique`, `revised` (or `None`), `score_before`, `score_after` (or `None`), `accepted`.

Rules:

1. Score the initial draft. If `target` is not `None` and the score already reaches it, stop at once with reason `"target"` (zero calls, empty history).
2. Each iteration: `critique = critique_fn(current)`. If it starts with `ok_marker` (case-insensitive), stop with `"critique_ok"` (record the iteration with `revised=None`, `accepted=False`).
3. Otherwise `revised = revise_fn(current, critique)`, `new = score_fn(revised)`. **Accept** the revision if `new >= current_score` when `accept="not_worse"` (the book's rule) or `new > current_score` when `accept="strict"`.
4. A revision *improves* if `new > current_score` (compare before updating). After an iteration, if the target is reached stop with `"target"`; if `stale >= patience` consecutive non-improving iterations stop with `"patience"`.
5. After `max_iters` iterations without another reason, stop with `"max_iters"`.

class Scripted:
    """Scripted 'model': each iteration k returns the k-th (critique, revised) pair; scores come from a dict."""
    def __init__(self, steps, scores):
        self.steps, self.scores = steps, scores
        self.k_c = 0
        self.k_r = 0
    def critique(self, draft):
        out = self.steps[self.k_c][0]
        self.k_c += 1
        return out
    def revise(self, draft, critique):
        out = self.steps[self.k_r][1]
        self.k_r += 1
        return out
    def score(self, draft):
        return self.scores[draft]

def run(steps, scores, initial="d0", **kw):
    s = Scripted(steps, scores)
    return refine_loop(initial, s.critique, s.revise, s.score, **kw)

def refine_loop(initial, critique_fn, revise_fn, score_fn, max_iters=3, patience=2,
                target=None, ok_marker="LGTM", accept="not_worse"):
    current = initial
    cur_score = score_fn(current)
    history = []
    calls = 0
    stale = 0
    reason = "max_iters"
    if target is not None and cur_score >= target:
        return {"final": current, "score": cur_score, "stop_reason": "target", "llm_calls": 0, "history": history}
    for it in range(1, max_iters + 1):
        critique = critique_fn(current)
        calls += 1
        if critique.strip().upper().startswith(ok_marker.upper()):
            history.append({"iteration": it, "critique": critique, "revised": None,
                            "score_before": cur_score, "score_after": None, "accepted": False})
            reason = "critique_ok"
            break
        revised = revise_fn(current, critique)
        calls += 1
        new = score_fn(revised)
        accepted = new >= cur_score if accept == "not_worse" else new > cur_score
        improved = new > cur_score
        history.append({"iteration": it, "critique": critique, "revised": revised,
                        "score_before": cur_score, "score_after": new, "accepted": accepted})
        if accepted:
            current, cur_score = revised, new
        stale = 0 if improved else stale + 1
        if target is not None and cur_score >= target:
            reason = "target"
            break
        if stale >= patience:
            reason = "patience"
            break
    return {"final": current, "score": cur_score, "stop_reason": reason, "llm_calls": calls, "history": history}
