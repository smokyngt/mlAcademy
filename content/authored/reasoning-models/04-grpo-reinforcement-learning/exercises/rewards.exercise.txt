Reinforcement learning with verifiable rewards needs (1) a reward per rollout and (2) an **advantage** that says whether a rollout was better or worse than its siblings. Implement both with the standard library and NumPy. The helpers `get_last_boxed` and `grade_answer` (a simplified checker for plain numbers and fractions) are provided.

- `reward_correct(text, gt)`: `1.0` if the **last boxed** answer exists and equals `gt`, else `0.0`. (No box means no reward, even if the text contains the right number.)
- `reward_format(text)`: `1.0` if `<think>` occurs and `</think>` occurs after it, else `0.0`.
- `total_reward(text, gt, format_weight=1.0, conditional=False)`: `correct + format_weight * format`; when `conditional=True` the format term is multiplied by the correctness reward, so formatting only pays when the answer is right.
- `group_advantages(rewards, eps=1e-4, std_norm=True)`: `(r - mean) / (std + eps)` with the **sample** standard deviation (`ddof=1`); with `std_norm=False` just `r - mean`.
- `binary_advantages(k, G)`: closed form (take `eps = 0`) of the advantages for `k` correct rollouts out of `G` (`0 < k < G`): return `(advantage_of_a_correct_one, advantage_of_a_wrong_one)`.
- `zero_signal_prob(p, G)`: probability that all `G` independent rollouts of a problem with success probability `p` get the same reward (so every advantage is 0 and the problem teaches nothing).

import numpy as np
from fractions import Fraction


def get_last_boxed(text):
    start = text.rfind("\\boxed")
    if start == -1:
        return None
    i = start + len("\\boxed")
    while i < len(text) and text[i].isspace():
        i += 1
    if i >= len(text) or text[i] != "{":
        return None
    i += 1
    depth, begin = 1, i
    while i < len(text) and depth > 0:
        depth += (text[i] == "{") - (text[i] == "}")
        i += 1
    return text[begin:i - 1] if depth == 0 else None


def grade_answer(pred, gt):
    def val(s):
        s = s.strip().strip("$ ").rstrip(".")
        try:
            return Fraction(s)
        except (ValueError, ZeroDivisionError):
            return s
    return val(pred) == val(gt)


def reward_correct(text, gt):
    boxed = get_last_boxed(text)
    if not boxed:
        return 0.0
    return float(grade_answer(boxed, gt))


def reward_format(text):
    a = text.find("<think>")
    if a == -1:
        return 0.0
    b = text.find("</think>", a)
    return 1.0 if b != -1 else 0.0


def total_reward(text, gt, format_weight=1.0, conditional=False):
    c = reward_correct(text, gt)
    f = reward_format(text)
    if conditional:
        f *= c
    return c + format_weight * f


def group_advantages(rewards, eps=1e-4, std_norm=True):
    r = np.asarray(rewards, float)
    d = r - r.mean()
    if not std_norm:
        return d
    return d / (r.std(ddof=1) + eps)


def binary_advantages(k, G):
    sigma = np.sqrt(k * (G - k) / (G * (G - 1)))
    return (1 - k / G) / sigma, -(k / G) / sigma


def zero_signal_prob(p, G):
    return p ** G + (1 - p) ** G
