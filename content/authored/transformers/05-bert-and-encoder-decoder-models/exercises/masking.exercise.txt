Implement three pieces of the encoder / denoising pre-training objectives, with all randomness passed in so that results are deterministic.

1. `mask_tokens(tokens, select_u, action_u, random_tokens, mask_id, p=0.15)`: `tokens`, `select_u`, `action_u`, `random_tokens` are 1-D arrays of the same length `T`. A position is *selected* if `select_u[i] < p`. For a selected position, if `action_u[i] < 0.8` the input becomes `mask_id`; elif `action_u[i] < 0.9` it becomes `random_tokens[i]`; else it is left unchanged. Return `(inputs, labels)`; `labels[i]` is the original token at selected positions and `-1` elsewhere.
2. `mlm_loss(logits, labels)`: `logits` has shape `(T, V)`. Average cross-entropy over positions whose label is not `-1` (return `0.0` if there are none).
3. `span_corrupt(tokens, spans, sentinel_base)`: `spans` is a sorted list of non-overlapping `(start, length)`. Return `(inputs, targets)` as Python lists. Every span is replaced in the input by one sentinel id `sentinel_base + j` (j = span index); the target is, for each span, its sentinel followed by the removed tokens, and finally one extra closing sentinel `sentinel_base + len(spans)`.

import numpy as np

def mask_tokens(tokens, select_u, action_u, random_tokens, mask_id, p=0.15):
    tokens = np.asarray(tokens)
    inputs = tokens.copy()
    labels = np.full(tokens.shape, -1)
    sel = np.asarray(select_u) < p
    labels[sel] = tokens[sel]
    for i in np.where(sel)[0]:
        if action_u[i] < 0.8:
            inputs[i] = mask_id
        elif action_u[i] < 0.9:
            inputs[i] = random_tokens[i]
    return inputs, labels

def mlm_loss(logits, labels):
    labels = np.asarray(labels)
    sel = labels != -1
    if not sel.any():
        return 0.0
    z = logits[sel]
    z = z - z.max(axis=1, keepdims=True)
    logp = z - np.log(np.exp(z).sum(axis=1, keepdims=True))
    return float(-logp[np.arange(len(z)), labels[sel]].mean())

def span_corrupt(tokens, spans, sentinel_base):
    inputs, targets = [], []
    pos = 0
    for j, (s, n) in enumerate(spans):
        inputs.extend(tokens[pos:s])
        inputs.append(sentinel_base + j)
        targets.append(sentinel_base + j)
        targets.extend(tokens[s:s + n])
        pos = s + n
    inputs.extend(tokens[pos:])
    targets.append(sentinel_base + len(spans))
    return inputs, targets
