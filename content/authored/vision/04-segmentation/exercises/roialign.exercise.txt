The feature map `feat` is a 2-D array `(H, W)`; the value of pixel `(row i, col j)` sits at the real-valued coordinate `(y=i, x=j)`.

- `bilinear_sample(feat, y, x)`: value at a real-valued position, blending the four surrounding pixels by distance; positions are clamped into `[0, H-1] x [0, W-1]`.
- `roi_align(feat, box, out_size)`: `box = (x1, y1, x2, y2)` in feature-map coordinates (floats allowed). Split the box into `out_size x out_size` equal bins and return the bilinear sample at each bin **centre**, shape `(out_size, out_size)`. (The real operator averages several samples per bin; one is enough to see the idea.)
- `roi_pool_rounded(feat, box, out_size)`: the older behaviour: round the box corners to integers first, then do the same sampling. Used to measure the misalignment.

import numpy as np

def bilinear_sample(feat, y, x):
    H, W = feat.shape
    y = min(max(y, 0.0), H - 1.0)
    x = min(max(x, 0.0), W - 1.0)
    y0, x0 = int(np.floor(y)), int(np.floor(x))
    y1, x1 = min(y0 + 1, H - 1), min(x0 + 1, W - 1)
    wy, wx = y - y0, x - x0
    return ((1 - wy) * (1 - wx) * feat[y0, x0] + (1 - wy) * wx * feat[y0, x1]
            + wy * (1 - wx) * feat[y1, x0] + wy * wx * feat[y1, x1])

def roi_align(feat, box, out_size):
    x1, y1, x2, y2 = box
    bh, bw = (y2 - y1) / out_size, (x2 - x1) / out_size
    out = np.zeros((out_size, out_size))
    for i in range(out_size):
        for j in range(out_size):
            out[i, j] = bilinear_sample(feat, y1 + (i + 0.5) * bh, x1 + (j + 0.5) * bw)
    return out

def roi_pool_rounded(feat, box, out_size):
    return roi_align(feat, tuple(float(np.round(v)) for v in box), out_size)
