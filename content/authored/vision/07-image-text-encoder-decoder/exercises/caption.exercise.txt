Implement the pieces of a "Show, Attend and Tell" style captioner at toy scale.

1. `softmax(x)` (stable, last axis).
2. `attend(h_prev, A, W_att)`: `A` holds `R` region features of size `D`, shape `(R, D)`; `h_prev` has size `H`; `W_att` has shape `(D, H)`. Score of region i is `A[i] . (W_att @ h_prev)`. Return `(alpha, z)` with `alpha` of shape `(R,)` summing to 1 and context `z = sum_i alpha_i A[i]` of shape `(D,)`.
3. `decoder_step(emb, h_prev, A, P)`: `P` is a dict with `W_att, Wx, Wz, Wh, b, Wo`. Return `(logits, h, alpha)` where `h = tanh(Wx @ emb + Wz @ z + Wh @ h_prev + b)` and `logits = Wo @ h`.
4. `apply_temperature(p, t)`: raise each probability to `1/t` and renormalise.
5. `bleu1(candidate, references)`: BLEU with unigrams only: clipped precision times brevity penalty. Words are given as lists of strings. Return a float (0 if the candidate is empty).
6. `answer_prior_baseline(train_answers, test_answers)`: always answer with the most frequent training answer (ties: the one that sorts first); return its accuracy on `test_answers`. This is the "language prior" baseline that exposes VQA dataset bias.

import numpy as np

def softmax(x):
    x = np.asarray(x, dtype=float)
    e = np.exp(x - x.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

def attend(h_prev, A, W_att):
    q = W_att @ h_prev
    e = A @ q
    alpha = softmax(e)
    z = alpha @ A
    return alpha, z

def decoder_step(emb, h_prev, A, P):
    alpha, z = attend(h_prev, A, P["W_att"])
    h = np.tanh(P["Wx"] @ emb + P["Wz"] @ z + P["Wh"] @ h_prev + P["b"])
    return P["Wo"] @ h, h, alpha

def apply_temperature(p, t):
    q = np.asarray(p, dtype=float) ** (1.0 / t)
    return q / q.sum()

def bleu1(candidate, references):
    if len(candidate) == 0:
        return 0.0
    from collections import Counter
    cc = Counter(candidate)
    clipped = 0
    for w, n in cc.items():
        clipped += min(n, max(Counter(r)[w] for r in references))
    prec = clipped / len(candidate)
    c = len(candidate)
    r = min((abs(len(r) - c), len(r)) for r in references)[1]
    bp = 1.0 if c > r else float(np.exp(1 - r / c))
    return prec * bp

def answer_prior_baseline(train_answers, test_answers):
    from collections import Counter
    cnt = Counter(train_answers)
    best = sorted(cnt.items(), key=lambda kv: (-kv[1], kv[0]))[0][0]
    return sum(a == best for a in test_answers) / len(test_answers)
