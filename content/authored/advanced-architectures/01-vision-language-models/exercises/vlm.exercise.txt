#@@ prompt
Implement the building blocks of a vision-language model with NumPy.

1. `n_patches(h, w, patch)` -> number of non-overlapping `patch x patch` patches that fit in an `h x w` image (ignore the remainder pixels).
2. `anyres_tokens(rows, cols, tokens_per_tile, thumbnail=True)` -> visual tokens for a LLaVA-NeXT style AnyRes layout: `rows*cols` tiles, plus one extra global thumbnail of the same token count when `thumbnail` is true.
3. `gelu(x)` with the tanh approximation `0.5 x (1 + tanh(sqrt(2/pi) (x + 0.044715 x^3)))`.
4. `mlp_projector(F, W1, b1, W2, b2)` -> `gelu(F @ W1 + b1) @ W2 + b2`. `F` has shape `(N, d_vis)`, result `(N, d_llm)`.
5. `qformer_cross_attention(queries, F, Wq, Wk, Wv)` -> `(out, attn)`. `queries` is `(n_q, d)`, `F` is `(N, d_vis)`, `Wq` is `(d, d_k)`, `Wk` is `(d_vis, d_k)`, `Wv` is `(d_vis, d_v)`. `attn` is `(n_q, N)` with rows summing to 1, `out = attn @ V` has shape `(n_q, d_v)`.
6. `splice_image_tokens(text_emb, image_tok, position)` -> the text embedding sequence `(T, d)` with the image tokens `(M, d)` inserted before row `position`; result `(T + M, d)`.

import numpy as np

def n_patches(h, w, patch):
    return (h // patch) * (w // patch)

def anyres_tokens(rows, cols, tokens_per_tile, thumbnail=True):
    return (rows * cols + (1 if thumbnail else 0)) * tokens_per_tile

def gelu(x):
    return 0.5 * x * (1.0 + np.tanh(np.sqrt(2.0 / np.pi) * (x + 0.044715 * x ** 3)))

def mlp_projector(F, W1, b1, W2, b2):
    return gelu(F @ W1 + b1) @ W2 + b2

def qformer_cross_attention(queries, F, Wq, Wk, Wv):
    Q = queries @ Wq
    K = F @ Wk
    V = F @ Wv
    s = Q @ K.T / np.sqrt(K.shape[1])
    s = s - s.max(axis=1, keepdims=True)
    e = np.exp(s)
    attn = e / e.sum(axis=1, keepdims=True)
    return attn @ V, attn

def splice_image_tokens(text_emb, image_tok, position):
    return np.concatenate([text_emb[:position], image_tok, text_emb[position:]], axis=0)
