Implement the arithmetic of large-scale training with NumPy.

1. `model_state_gib(psi, n_gpus, stage, bytes_param=2, bytes_grad=2, bytes_opt=12)`: per-GPU GiB (2**30 bytes) for parameters, gradients and optimizer state of a `psi`-parameter model when ZeRO stage `stage` (0 = plain data parallel, 1 = shard optimizer state, 2 = also gradients, 3 = also parameters) is used on `n_gpus`. Activations are NOT included.
2. `min_gpus(psi, stage, budget_gib)`: smallest number of GPUs (>= 1) whose per-GPU model state fits in `budget_gib`, or `None` if even 100000 GPUs would not fit (stage 0 never improves with more GPUs).
3. `column_parallel(x, W, n)`: tensor parallelism, split `W` `(d_in, d_out)` into `n` column blocks, compute each `x @ W_i` separately, concatenate. `row_parallel(x, W, n)`: split `x` columns and `W` rows into `n` blocks and sum the partial products (the all-reduce). Both must equal `x @ W`.
4. `bubble_fraction(p, m)`: fraction of the pipeline's time that a stage is idle with `p` stages and `m` micro-batches (GPipe-style): `(p-1)/(m+p-1)`. `bubble_overhead(p, m)`: extra time relative to the ideal, `(p-1)/m`.
5. `checkpoint_memory(L, k, a_in, a_layer)`: activation memory when keeping only the input of every k-th layer and recomputing inside segments: `ceil(L/k)*a_in + k*a_layer`. `best_k(L, a_in, a_layer)`: the k in `1..L` minimising it (smallest k on ties). `step_cost_factor(recompute_fraction)`: FLOPs of one training step relative to no checkpointing, where a forward costs 1 unit, a backward 2, and `recompute_fraction` of a forward is repeated: `(3 + r)/3`.
6. `scaled_fp16_grad(g, scale)`: cast `g * scale` to `np.float16`, then return it back as float32 divided by `scale`. `dynamic_scale(scale, found_inf, good_steps, growth_interval=2000)` -> `(new_scale, new_good_steps)`: on overflow halve the scale and reset the counter; otherwise increment the counter and, when it reaches `growth_interval`, double the scale and reset it.
7. `mtp_loss(logits_list, tokens, lam)`: `logits_list[d]` has shape `(T, V)` and head `d` predicts the token `d + 1` positions ahead (head 0 is the usual next-token head). For each head the cross-entropy is averaged over the positions `i` for which `tokens[i + 1 + d]` exists, i.e. `i < len(tokens) - 1 - d` (use only the first `len(tokens) - 1 - d` rows of the logits). Return `(main, extra)` where `main` is head 0's loss and `extra = lam / D * sum(loss_d for d = 1..D)` with `D = len(logits_list) - 1` (0 if `D = 0`).

import numpy as np

def model_state_gib(psi, n_gpus, stage, bytes_param=2, bytes_grad=2, bytes_opt=12):
    p, g, o = bytes_param * psi, bytes_grad * psi, bytes_opt * psi
    if stage >= 1:
        o = o / n_gpus
    if stage >= 2:
        g = g / n_gpus
    if stage >= 3:
        p = p / n_gpus
    return (p + g + o) / 2 ** 30

def min_gpus(psi, stage, budget_gib):
    for n in range(1, 100001):
        if model_state_gib(psi, n, stage) <= budget_gib:
            return n
        if stage == 0:
            return None
    return None

def column_parallel(x, W, n):
    return np.concatenate([x @ B for B in np.array_split(W, n, axis=1)], axis=1)

def row_parallel(x, W, n):
    xs = np.array_split(x, n, axis=1)
    Ws = np.array_split(W, n, axis=0)
    return sum(a @ b for a, b in zip(xs, Ws))

def bubble_fraction(p, m):
    return (p - 1) / (m + p - 1)

def bubble_overhead(p, m):
    return (p - 1) / m

def checkpoint_memory(L, k, a_in, a_layer):
    return int(np.ceil(L / k)) * a_in + k * a_layer

def best_k(L, a_in, a_layer):
    best, best_mem = 1, checkpoint_memory(L, 1, a_in, a_layer)
    for k in range(2, L + 1):
        mem = checkpoint_memory(L, k, a_in, a_layer)
        if mem < best_mem - 1e-12:
            best, best_mem = k, mem
    return best

def step_cost_factor(recompute_fraction):
    return (3 + recompute_fraction) / 3

def scaled_fp16_grad(g, scale):
    with np.errstate(over="ignore"):
        h = (np.asarray(g, dtype=np.float32) * np.float32(scale)).astype(np.float16)
    return h.astype(np.float32) / np.float32(scale)

def dynamic_scale(scale, found_inf, good_steps, growth_interval=2000):
    if found_inf:
        return scale / 2, 0
    good_steps += 1
    if good_steps >= growth_interval:
        return scale * 2, 0
    return scale, good_steps

def _ce(logits, targets):
    z = logits - logits.max(axis=1, keepdims=True)
    logp = z - np.log(np.exp(z).sum(axis=1, keepdims=True))
    return float(-np.mean(logp[np.arange(len(targets)), targets]))

def mtp_loss(logits_list, tokens, lam):
    losses = []
    for d, lg in enumerate(logits_list):
        n = len(tokens) - 1 - d
        losses.append(_ce(lg[:n], tokens[1 + d:1 + d + n]))
    D = len(logits_list) - 1
    extra = lam / D * sum(losses[1:]) if D > 0 else 0.0
    return losses[0], extra
