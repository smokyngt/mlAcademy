Implement linear state-space recurrences in NumPy.

1. `ssm_recurrent(x, a, b, c)`: one input channel, state size `n`. `x` is `(T,)`, `a, b, c` are `(n,)`. Run `h_t = a * h_{t-1} + b * x_t` (elementwise, `h_{-1} = 0`), `y_t = sum(c * h_t)`. Return `y` of shape `(T,)`.
2. `ssm_kernel(a, b, c, T)`: the convolution kernel `K_k = sum(c * a**k * b)` for `k = 0..T-1`, shape `(T,)`.
3. `ssm_convolution(x, a, b, c)`: the same output computed as the causal convolution `y_t = sum_{k<=t} K_k x_{t-k}`.
4. `scan_combine(e1, e2)`: compose two affine maps `h -> a h + b`, each given as a tuple `(a, b)` (apply `e1` first, then `e2`): returns `(a1*a2, a2*b1 + b2)`.
5. `sequential_scan(a, b)`: `a` and `b` are `(T,)` arrays; return `h` with `h_t = a_t h_{t-1} + b_t`, `h_{-1} = 0`.
6. `parallel_scan(a, b)`: the same result computed with the Hillis-Steele inclusive scan using `scan_combine`; return `(h, steps)` where `steps` is the number of doubling rounds performed.
7. `selective_scan(x, delta, A, B, C)`: Mamba-style selective SSM. `x` is `(T, D)`, `delta` is `(T, D)` positive step sizes, `A` is `(D, n)` negative (continuous decay rates), `B` and `C` are `(T, n)` input-dependent. Discretise per step: `A_bar = exp(delta_t[:, None] * A)`, `B_bar = delta_t[:, None] * B_t[None, :]`. State `h` is `(D, n)`: `h = A_bar * h + B_bar * x_t[:, None]`; output `y_t = h @ C_t` of shape `(D,)`. Return `(T, D)`.
8. `hybrid_memory_gib(layout, repeats, kv_heads, head_dim, n_tokens, d_model, state_size, bytes_per_value=2)`: `layout` is a string such as `"MMMMMMMA"` (M = SSM layer, A = attention layer) repeated `repeats` times. Attention layers cache `2*kv_heads*head_dim*n_tokens*bytes` each; every SSM layer holds a fixed state of `d_model*state_size*bytes`. Return total GiB (2**30 bytes).

import numpy as np

def ssm_recurrent(x, a, b, c):
    h = np.zeros_like(a, dtype=float)
    y = np.zeros(len(x))
    for t in range(len(x)):
        h = a * h + b * x[t]
        y[t] = np.sum(c * h)
    return y

def ssm_kernel(a, b, c, T):
    return np.array([np.sum(c * a ** k * b) for k in range(T)])

def ssm_convolution(x, a, b, c):
    T = len(x)
    K = ssm_kernel(a, b, c, T)
    return np.array([np.sum(K[:t + 1] * x[t::-1]) for t in range(T)])

def scan_combine(e1, e2):
    return (e1[0] * e2[0], e2[0] * e1[1] + e2[1])

def sequential_scan(a, b):
    h = np.zeros(len(a))
    prev = 0.0
    for t in range(len(a)):
        prev = a[t] * prev + b[t]
        h[t] = prev
    return h

def parallel_scan(a, b):
    A = np.array(a, dtype=float)
    B = np.array(b, dtype=float)
    T = len(A)
    offset, steps = 1, 0
    while offset < T:
        newA, newB = A.copy(), B.copy()
        for i in range(offset, T):
            newA[i], newB[i] = scan_combine((A[i - offset], B[i - offset]), (A[i], B[i]))
        A, B = newA, newB
        offset *= 2
        steps += 1
    return B, steps

def selective_scan(x, delta, A, B, C):
    T, D = x.shape
    n = A.shape[1]
    h = np.zeros((D, n))
    y = np.zeros((T, D))
    for t in range(T):
        Abar = np.exp(delta[t][:, None] * A)
        Bbar = delta[t][:, None] * B[t][None, :]
        h = Abar * h + Bbar * x[t][:, None]
        y[t] = h @ C[t]
    return y

def hybrid_memory_gib(layout, repeats, kv_heads, head_dim, n_tokens, d_model, state_size, bytes_per_value=2):
    n_attn = layout.count("A") * repeats
    n_ssm = layout.count("M") * repeats
    kv = n_attn * 2 * kv_heads * head_dim * n_tokens * bytes_per_value
    st = n_ssm * d_model * state_size * bytes_per_value
    return (kv + st) / 2 ** 30
