Implement the pieces of a sparse mixture-of-experts layer with NumPy.

1. `softmax(z)` over the last axis (numerically stable).
2. `topk_route(logits, k, bias=None)` -> `(idx, gates)`. `logits` is `(N, E)`. Experts are selected by the top-`k` of `logits + bias` (bias defaults to zeros; ties broken by lower index). `idx` has shape `(N, k)` ordered by decreasing score; `gates` has shape `(N, k)` and is the softmax of the **raw** `logits` restricted to the selected experts (so each row sums to 1).
3. `balance_loss(logits, idx, alpha=1.0)`: the Switch-style auxiliary loss `alpha * E * sum_i f_i * P_i` where `f_i` is the fraction of the `N*k` assignments sent to expert `i` and `P_i` is the mean over tokens of the full softmax probability of expert `i`.
4. `capacity(N, k, E, cf)` = `ceil(cf * N * k / E)`.
5. `dispatch_with_capacity(idx, E, cap)` -> boolean `(N, k)` array `keep`: process tokens in order (and slots left to right); an assignment is kept only if its expert has accepted fewer than `cap` assignments so far; otherwise it is dropped.
6. `moe_forward(x, Wr, We, k, Wshared=None)`: `x` is `(N, d)`, router weights `Wr` `(d, E)`, expert weights `We` `(E, d, d)` (each expert is the linear map `x @ We[e]`). Output `(N, d)` = `sum_j gates[:, j] * (x @ We[idx[:, j]])` (+ `x @ Wshared` if given, applied to every token).
7. `update_bias(bias, counts, gamma)`: auxiliary-loss-free balancing step, `bias - gamma * sign(counts - counts.mean())`.
8. `param_counts(E, k, d, dff, n_shared=0)` -> `(total, active)` feed-forward parameters of one MoE layer where each expert is a SwiGLU FFN with 3 matrices of size `d x dff`; shared experts are always active.

import numpy as np

def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)

def topk_route(logits, k, bias=None):
    scores = logits if bias is None else logits + bias
    idx = np.argsort(-scores, axis=1, kind="stable")[:, :k]
    chosen = np.take_along_axis(logits, idx, axis=1)
    return idx, softmax(chosen)

def balance_loss(logits, idx, alpha=1.0):
    N, E = logits.shape
    f = np.bincount(idx.ravel(), minlength=E) / idx.size
    P = softmax(logits).mean(axis=0)
    return float(alpha * E * np.sum(f * P))

def capacity(N, k, E, cf):
    return int(np.ceil(cf * N * k / E))

def dispatch_with_capacity(idx, E, cap):
    keep = np.zeros(idx.shape, dtype=bool)
    count = np.zeros(E, dtype=int)
    for n in range(idx.shape[0]):
        for j in range(idx.shape[1]):
            e = idx[n, j]
            if count[e] < cap:
                count[e] += 1
                keep[n, j] = True
    return keep

def moe_forward(x, Wr, We, k, Wshared=None):
    idx, gates = topk_route(x @ Wr, k)
    y = np.zeros_like(x)
    for j in range(k):
        out = np.einsum("nd,nde->ne", x, We[idx[:, j]])
        y += gates[:, j:j + 1] * out
    if Wshared is not None:
        y += x @ Wshared
    return y

def update_bias(bias, counts, gamma):
    return bias - gamma * np.sign(counts - counts.mean())

def param_counts(E, k, d, dff, n_shared=0):
    per = 3 * d * dff
    return (E + n_shared) * per, (k + n_shared) * per
