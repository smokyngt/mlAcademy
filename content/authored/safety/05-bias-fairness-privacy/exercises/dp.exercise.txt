A randomised algorithm `M` is (epsilon, delta)-differentially private if for neighbouring datasets `D, D'` and every event `S`: `P(M(D) in S) <= exp(epsilon) * P(M(D') in S) + delta`.

Implement:

- `laplace_release(value, sensitivity, eps, rng, size)`: `value` plus Laplace noise of scale `sensitivity/eps`, `size` independent draws.
- `gaussian_sigma(sensitivity, eps, delta)`: the classical calibration `sensitivity*sqrt(2*ln(1.25/delta))/eps` (valid for `eps < 1`).
- `gaussian_release(value, sigma, rng, size)`.
- `dp_violation(x_d, x_dp, eps, delta, thresholds)`: from samples of `M(D)` and `M(D')`, the largest excess of the (eps, delta) inequality over events `S = {x > t}`, in both directions (positive means a detected violation, up to sampling error).
- `clip_rows(G, C)`: scale each row of per-example gradients `G` of shape `(B, d)` to L2 norm at most `C`.
- `dp_sgd_sum(G, C, sigma, rng)`: the noisy aggregated gradient `sum(clip_rows(G, C)) + N(0, (sigma*C)^2 I)`, shape `(d,)`.
- `basic_composition(eps_list, delta_list)`: total (epsilon, delta) of sequential release by adding.

The query is a count with sensitivity 1; neighbouring datasets give counts 100 and 101.

import math
import numpy as np

def laplace_release(value, sensitivity, eps, rng, size):
    return value + rng.laplace(0.0, sensitivity / eps, size)

def gaussian_sigma(sensitivity, eps, delta):
    return sensitivity * math.sqrt(2.0 * math.log(1.25 / delta)) / eps

def gaussian_release(value, sigma, rng, size):
    return value + sigma * rng.normal(size=size)

def dp_violation(x_d, x_dp, eps, delta, thresholds):
    worst = -1.0
    for t in thresholds:
        p = float((x_d > t).mean())
        q = float((x_dp > t).mean())
        worst = max(worst, q - math.exp(eps) * p - delta, p - math.exp(eps) * q - delta)
    return worst

def clip_rows(G, C):
    norms = np.linalg.norm(G, axis=1, keepdims=True)
    return G * np.minimum(1.0, C / np.maximum(norms, 1e-12))

def dp_sgd_sum(G, C, sigma, rng):
    return clip_rows(G, C).sum(axis=0) + sigma * C * rng.normal(size=G.shape[1])

def basic_composition(eps_list, delta_list):
    return float(sum(eps_list)), float(sum(delta_list))
