A synthetic risk score `s` is **perfectly calibrated in both groups by construction** (the label is drawn with probability `s`), but the groups have different score distributions and therefore different base rates. `make_data` (given) returns group `g`, score `s`, label `y`.

Implement, for a boolean prediction array `pred` and a mask of one group:

- `selection_rate(pred, mask)`, `tpr(pred, y, mask)`, `fpr(pred, y, mask)`, `ppv(pred, y, mask)`;
- `dp_gap(pred, g)`: absolute difference of selection rates between groups 0 and 1 (demographic parity);
- `eo_gap(pred, y, g)`: the larger of the TPR gap and FPR gap (equalised odds);
- `ece(scores, y, bins=10)`: expected calibration error of one group;
- `threshold_for_tpr(scores, y, target)`: a score threshold whose TPR is at least `target`.

Then observe the trade-off: with one common threshold the groups differ in selection rate and error rates; lowering group 0's threshold to match group 1's TPR makes TPR equal but breaks equal precision (PPV) and still leaves FPR unequal.

import numpy as np

def make_data(n=20000, seed=0):
    rng = np.random.default_rng(seed)
    g = (rng.random(n) < 0.5).astype(int)
    s = np.where(g == 0, rng.beta(2, 5, n), rng.beta(4, 4, n))
    y = (rng.random(n) < s).astype(int)
    return g, s, y

def selection_rate(pred, mask):
    return float(pred[mask].mean())

def tpr(pred, y, mask):
    return float(pred[mask & (y == 1)].mean())

def fpr(pred, y, mask):
    return float(pred[mask & (y == 0)].mean())

def ppv(pred, y, mask):
    return float(y[mask & pred].mean())

def dp_gap(pred, g):
    return abs(selection_rate(pred, g == 0) - selection_rate(pred, g == 1))

def eo_gap(pred, y, g):
    m0, m1 = g == 0, g == 1
    return max(abs(tpr(pred, y, m0) - tpr(pred, y, m1)), abs(fpr(pred, y, m0) - fpr(pred, y, m1)))

def ece(scores, y, bins=10):
    idx = np.minimum((scores * bins).astype(int), bins - 1)
    total = 0.0
    for b in range(bins):
        m = idx == b
        if m.any():
            total += m.mean() * abs(scores[m].mean() - y[m].mean())
    return float(total)

def threshold_for_tpr(scores, y, target):
    pos = np.sort(scores[y == 1])
    return float(pos[int(np.floor((1 - target) * len(pos)))])
