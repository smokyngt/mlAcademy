Evaluating a defence means estimating how often attacks succeed, with honest uncertainty. All data here are abstract (booleans and counts); no prompts or attack text are involved.

Implement:

- `wilson_interval(k, n, z=1.96)` -> `(low, high)`, the Wilson score interval for a proportion `k/n`.
- `asr_at_budget(first_success, k)`: fraction of behaviours whose first successful attack came within `k` queries (`first_success[i]` is `np.inf` if never).
- `two_prop_z(k1, n1, k2, n2)`: pooled two-proportion z statistic for comparing two defences.
- `n_needed(p, half_width, z=1.96)`: smallest `n` so that a normal-approximation interval around `p` has the given half-width.
- `union_asr(M)`: `M` has shape `(behaviours, attacks)`; a behaviour counts as broken if any attack succeeds. Compare it with the best single-attack ASR (`best_single_asr(M)`): an adaptive evaluator reports the union, a static benchmark reports one column.
- `fit_power_law(x, y)` -> `(alpha, a)` with `y ~ a * x**(-alpha)`, by least squares on logs (used for benign in-context-learning error curves versus the number of examples).

import math
import numpy as np

def wilson_interval(k, n, z=1.96):
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, c - h), min(1.0, c + h)

def asr_at_budget(first_success, k):
    return float(np.mean(np.asarray(first_success, float) <= k))

def two_prop_z(k1, n1, k2, n2):
    p1, p2 = k1 / n1, k2 / n2
    p = (k1 + k2) / (n1 + n2)
    se = math.sqrt(p * (1 - p) * (1 / n1 + 1 / n2))
    return (p1 - p2) / se

def n_needed(p, half_width, z=1.96):
    return int(math.ceil(z * z * p * (1 - p) / half_width ** 2))

def union_asr(M):
    return float(np.asarray(M).any(axis=1).mean())

def best_single_asr(M):
    return float(np.asarray(M).mean(axis=0).max())

def fit_power_law(x, y):
    slope, intercept = np.polyfit(np.log(x), np.log(y), 1)
    return -float(slope), float(np.exp(intercept))
