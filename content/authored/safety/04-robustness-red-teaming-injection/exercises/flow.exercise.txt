Indirect prompt injection works because content fetched by an agent (a web page, an email) can steer what the agent does next. A classical defence idea is **information-flow control**: attach a label to every value, propagate labels through computation, and check them before side effects.

Everything here is a benign toy: plans are lists of abstract steps, with no real text.

Step types:
- `{"op": "read", "out": v, "label": L}` where `L` is `"user"`, `"untrusted"` or `"private"`;
- `{"op": "compute", "out": v, "inputs": [v1, v2, ...]}` (the output carries the union of the input labels);
- `{"op": "send", "inputs": [...], "to": "internal" | "external"}`.

Implement `run_plan(plan)` -> list of verdicts, one per `send` step in order, using these rules for a send: internal -> `"allow"`; external whose inputs carry both `untrusted` and `private` -> `"block"`; external with `untrusted` only -> `"confirm"` (a human must ratify); otherwise `"allow"`.

Also implement `trifecta(caps)`: a system is in the risky combination if its capabilities (a set of strings) include all of `"reads_private"`, `"reads_untrusted"` and `"sends_external"`.

def run_plan(plan):
    labels = {}
    verdicts = []
    for step in plan:
        if step["op"] == "read":
            labels[step["out"]] = {step["label"]}
        elif step["op"] == "compute":
            s = set()
            for v in step["inputs"]:
                s |= labels.get(v, set())
            labels[step["out"]] = s
        elif step["op"] == "send":
            s = set()
            for v in step["inputs"]:
                s |= labels.get(v, set())
            if step["to"] == "internal":
                verdicts.append("allow")
            elif "untrusted" in s and "private" in s:
                verdicts.append("block")
            elif "untrusted" in s:
                verdicts.append("confirm")
            else:
                verdicts.append("allow")
    return verdicts

def trifecta(caps):
    return {"reads_private", "reads_untrusted", "sends_external"} <= set(caps)
