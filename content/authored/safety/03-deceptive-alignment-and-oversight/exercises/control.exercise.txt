#@@ prompt
A **control protocol** assumes the strong model may be adversarial and asks how safe we can be anyway. Here is a small model of *trusted monitoring*:

- An untrusted model solves `N` tasks. In each task it attacks (inserts a flaw) with probability `p`; otherwise it behaves.
- A weaker **trusted monitor** gives every solution a suspicion score. Honest solutions score `N(0, 1)`; attacked ones score `N(mu, 1)` (`mu` is the monitor's power).
- Humans can audit only a fraction `f` of honest solutions (the **false-positive budget**). So the audit threshold is the value exceeded by an honest score with probability `f`. An audited attack is caught for sure; a caught attack ends the game with the blue team winning.
- An attack that is not audited succeeds in causing real harm with probability `q`; harm ends the game with the red team winning. An unaudited attack that does not succeed changes nothing.

Implement:
`norm_sf(z)`, `threshold_for_fpr(f)`, `catch_prob(mu, f)`, `safety_fixed(A, mu, f, q)` (probability blue wins when exactly `A` attacks are attempted), `safety_binomial(N, p, mu, f, q)` (average over `A ~ Binomial(N, p)`), and `simulate_safety(N, p, mu, f, q, T, seed)` (Monte Carlo over `T` games using `numpy.random.default_rng(seed)`; each game draws the attacked tasks first, then walks through them in order).

import math
import numpy as np

def norm_sf(z):
    return 0.5 * math.erfc(z / math.sqrt(2.0))

def threshold_for_fpr(f):
    lo, hi = -10.0, 10.0
    for _ in range(100):
        m = (lo + hi) / 2
        if norm_sf(m) > f:
            lo = m
        else:
            hi = m
    return (lo + hi) / 2

def catch_prob(mu, f):
    return norm_sf(threshold_for_fpr(f) - mu)

def safety_fixed(A, mu, f, q):
    c = catch_prob(mu, f)
    h = (1 - c) * q
    n = (1 - c) * (1 - q)
    return 1 - h / (c + h) * (1 - n ** A)

def safety_binomial(N, p, mu, f, q):
    total = 0.0
    for a in range(N + 1):
        total += math.comb(N, a) * p ** a * (1 - p) ** (N - a) * safety_fixed(a, mu, f, q)
    return total

def simulate_safety(N, p, mu, f, q, T, seed):
    rng = np.random.default_rng(seed)
    t = threshold_for_fpr(f)
    blue = 0
    for _ in range(T):
        res = 1
        attacked = np.nonzero(rng.random(N) < p)[0]
        for _a in attacked:
            if rng.normal(mu, 1.0) > t:
                res = 1
                break
            if rng.random() < q:
                res = 0
                break
        blue += res
    return blue / T
