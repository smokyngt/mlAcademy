Simulate how optimisation pressure on a proxy damages the true objective.

Candidates have a true quality `q` and an exploitable feature `x`. The proxy score is `q + a*x`; the gold score is `q - b*(x - 1)`. `make_candidates` (given) returns arrays of shape `(P, N)`.

Implement:

- `bon_curve(q, x, a, b, ns)` -> array of shape `(len(ns), 2)`: for each `n`, choose per prompt the candidate with the highest proxy among the first `n`, and return the mean proxy and mean gold of the chosen candidates.
- `bon_kl(n)` -> `log(n) - (n-1)/n`, the usual KL estimate for best-of-n.
- `peak_index(curve)` -> index of the `n` at which mean gold is largest.
- `tilted_policy(pi_ref, r, beta)` -> the KL-regularised optimum `pi_ref * exp(r/beta) / Z`.
- `penalised_reward(r, agree, alpha)` -> `r - alpha * agree` (elementwise).

import numpy as np

def make_candidates(P=2000, N=64, seed=0):
    rng = np.random.default_rng(seed)
    return rng.normal(size=(P, N)), rng.exponential(1.0, size=(P, N))

def bon_curve(q, x, a, b, ns):
    rows = np.arange(len(q))
    out = []
    for n in ns:
        proxy = q[:, :n] + a * x[:, :n]
        gold = q[:, :n] - b * (x[:, :n] - 1.0)
        i = proxy.argmax(axis=1)
        out.append((proxy[rows, i].mean(), gold[rows, i].mean()))
    return np.array(out)

def bon_kl(n):
    return float(np.log(n) - (n - 1) / n)

def peak_index(curve):
    return int(np.argmax(curve[:, 1]))

def tilted_policy(pi_ref, r, beta):
    w = np.asarray(pi_ref) * np.exp(np.asarray(r) / beta)
    return w / w.sum()

def penalised_reward(r, agree, alpha):
    return np.asarray(r) - alpha * np.asarray(agree)
