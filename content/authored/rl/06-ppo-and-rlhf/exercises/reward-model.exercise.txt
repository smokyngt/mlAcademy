Humans compare pairs of responses; a **reward model** (RM) turns those comparisons into a scalar score. Here the RM is linear on feature vectors: $R_w(x)=w\cdot x$ with `w` of shape `(d,)`. A pair is `(x_pos, x_neg)` where `x_pos` is the preferred response (arrays of shape `(N, d)`).

Implement:

- `bt_loss(w, Xp, Xn)` -> the Bradley-Terry loss $-\frac1N\sum_i\log\sigma\big(R_w(x^+_i)-R_w(x^-_i)\big)$.
- `bt_grad(w, Xp, Xn)` -> its gradient, shape `(d,)`.
- `train_rm(Xp, Xn, lr, steps)` -> weights after gradient descent from zeros.
- `pairwise_accuracy(w, Xp, Xn)` -> fraction of pairs with `R(x_pos) > R(x_neg)`.
- `rlhf_reward(r, logp_policy, logp_ref, beta)` -> the shaped reward $r-\beta(\log\pi_\theta-\log\pi_{\text{ref}})$ used inside PPO (a sampled estimate of a KL penalty).

import numpy as np

def bt_loss(w, Xp, Xn):
    m = (Xp - Xn) @ w
    return float(np.mean(np.logaddexp(0.0, -m)))

def bt_grad(w, Xp, Xn):
    D = Xp - Xn
    m = D @ w
    s = 0.5 * (1.0 + np.tanh(0.5 * m))          # stable sigmoid
    return -np.mean((1.0 - s)[:, None] * D, axis=0)

def train_rm(Xp, Xn, lr=0.5, steps=500):
    w = np.zeros(Xp.shape[1])
    for _ in range(steps):
        w = w - lr * bt_grad(w, Xp, Xn)
    return w

def pairwise_accuracy(w, Xp, Xn):
    return float(np.mean(Xp @ w > Xn @ w))

def rlhf_reward(r, logp_policy, logp_ref, beta):
    return r - beta * (logp_policy - logp_ref)
