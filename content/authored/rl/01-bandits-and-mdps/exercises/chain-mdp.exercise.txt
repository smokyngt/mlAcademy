A chain MDP has states `0..n-1`; the last one is terminal. Action 1 ("right") moves one step right with probability `p` and otherwise stays; action 0 moves left (or stays at 0) with probability `p`. Reaching the last state gives reward 1.

`make_chain` is given. Implement:

- `rollout(P, R, policy, s0, gamma, rng)` -> the discounted return of one episode starting in `s0`, following the deterministic `policy` (an int array: action per state) until the terminal state.
- `mc_value(P, R, policy, s0, gamma, n_episodes, seed)` -> the mean return over `n_episodes` rollouts.

The tests compare your estimate with the closed form $V(0)=\frac1\gamma\big(\frac{p\gamma}{1-(1-p)\gamma}\big)^{n-1}$ for the always-right policy.

import numpy as np

def make_chain(n=5, p=0.8):
    P = np.zeros((n, 2, n)); R = np.zeros((n, 2, n))
    for s in range(n - 1):
        P[s, 1, s + 1] = p; P[s, 1, s] += 1 - p
        P[s, 0, max(s - 1, 0)] += p; P[s, 0, s] += 1 - p
    R[n - 2, 1, n - 1] = 1.0
    P[n - 1, :, n - 1] = 1.0
    return P, R

def rollout(P, R, policy, s0, gamma, rng, max_steps=500):
    n = P.shape[0]
    s, G, disc = s0, 0.0, 1.0
    for _ in range(max_steps):
        if s == n - 1:
            break
        a = policy[s]
        s2 = int(rng.choice(n, p=P[s, a]))
        G += disc * R[s, a, s2]
        disc *= gamma
        s = s2
    return G

def mc_value(P, R, policy, s0, gamma, n_episodes, seed=0):
    rng = np.random.default_rng(seed)
    return float(np.mean([rollout(P, R, policy, s0, gamma, rng) for _ in range(n_episodes)]))
