Implement the building blocks of bandit learning and the return of an MDP episode.

- `discounted_return(rewards, gamma)` -> the return $G_0=\sum_k\gamma^k r_k$ of a list of rewards.
- `update_mean(Q, N, a, r)` -> new copies `(Q, N)` after observing reward `r` for arm `a` (incremental sample mean; `N` counts pulls). Do not modify the arguments.
- `epsilon_greedy_action(Q, eps, rng)` -> with probability `eps` a uniformly random arm (use `rng.random()` first, then `rng.integers`), otherwise `argmax(Q)`.
- `ucb_action(Q, N, t, c)` -> an unpulled arm first, otherwise the arm maximising `Q + c*sqrt(log(t)/N)`; `t` is the current step number (starting at 1).

The tests run both strategies on a 5-armed Gaussian bandit.

means = [0.1, 0.5, 0.3, 0.9, 0.2]
def run(select, steps, seed):
    rng = np.random.default_rng(seed)
    Q = np.zeros(5); N = np.zeros(5, dtype=int); total = 0.0
    for t in range(1, steps + 1):
        a = select(Q, N, t, rng)
        r = rng.normal(means[a], 1.0)
        Q, N = update_mean(Q, N, a, r)
        total += r
    return total / steps, N[3] / steps

def avg(select):
    res = [run(select, 1000, s) for s in range(10)]
    return np.mean([x[0] for x in res]), np.mean([x[1] for x in res])

import numpy as np

def discounted_return(rewards, gamma):
    g = 0.0
    for r in reversed(rewards):
        g = r + gamma * g
    return g

def update_mean(Q, N, a, r):
    Q = Q.copy(); N = N.copy()
    N[a] += 1
    Q[a] += (r - Q[a]) / N[a]
    return Q, N

def epsilon_greedy_action(Q, eps, rng):
    if rng.random() < eps:
        return int(rng.integers(len(Q)))
    return int(np.argmax(Q))

def ucb_action(Q, N, t, c):
    if np.any(N == 0):
        return int(np.argmin(N))
    return int(np.argmax(Q + c * np.sqrt(np.log(t) / N)))
