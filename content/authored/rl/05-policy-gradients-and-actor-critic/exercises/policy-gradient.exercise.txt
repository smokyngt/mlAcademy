A 3-armed bandit with a **softmax policy** $\pi_\theta(a)=\operatorname{softmax}(\theta)_a$, $\theta\in\mathbb{R}^3$, and deterministic arm rewards `r`. The objective is $J(\theta)=\sum_a\pi_\theta(a)r_a$.

Implement:

- `softmax(theta)` (numerically stable).
- `grad_log_pi(theta, a)` -> $\nabla_\theta\log\pi_\theta(a)$, shape `(3,)`.
- `expected_return(theta, r)` -> $J(\theta)$.
- `exact_gradient(theta, r)` -> the closed form $\partial J/\partial\theta_k=\pi_k(r_k-J)$.
- `pg_expectation(theta, r, b)` -> the policy-gradient theorem written as an exact expectation, $\sum_a\pi(a)(r_a-b)\nabla\log\pi(a)$.
- `reinforce_estimate(theta, actions, rewards, b)` -> the sample average of $(R-b)\nabla\log\pi(a)$ over sampled actions/rewards.
- `estimator_variance(theta, r, b)` -> the total variance (sum over the 3 coordinates) of one sample of $(R-b)\nabla\log\pi(a)$.

import numpy as np

def softmax(theta):
    z = theta - np.max(theta)
    e = np.exp(z)
    return e / e.sum()

def grad_log_pi(theta, a):
    g = -softmax(theta)
    g[a] += 1.0
    return g

def expected_return(theta, r):
    return float(softmax(theta) @ r)

def exact_gradient(theta, r):
    p = softmax(theta)
    return p * (r - p @ r)

def pg_expectation(theta, r, b):
    p = softmax(theta)
    return sum(p[a] * (r[a] - b) * grad_log_pi(theta, a) for a in range(len(theta)))

def reinforce_estimate(theta, actions, rewards, b):
    return np.mean([(R - b) * grad_log_pi(theta, a) for a, R in zip(actions, rewards)], axis=0)

def estimator_variance(theta, r, b):
    p = softmax(theta)
    mean = pg_expectation(theta, r, b)
    second = sum(p[a] * np.sum(((r[a] - b) * grad_log_pi(theta, a)) ** 2) for a in range(len(theta)))
    return float(second - np.sum(mean ** 2))
